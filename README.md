# GD Pattern Trainer

Geometry Dash 클릭 패턴 연습기. 빌드 없음 — `index.html` 하나를 브라우저로 열면 됨.

## 기능
- **녹화 + 배속**: 0.2x로 천천히 녹화하면 패턴은 실제 속도(1x)로 저장됨. 연습 속도 1x로 원래 속도 연습, 0.5x 등으로 단계적으로 올리기.
- **홀드 지원**: 누른 시간 기록, 홀드 노트는 뗌 타이밍도 판정 (`↑+3.2`).
- **연습**: 노트별 오차(ms) 표시, MISS / 빈 클릭, 시도별 평균·편차 기록. 구간 반복.
- **리플레이**: 마지막 시도를 내 클릭 소리와 함께 다시 재생.
- **매크로 재생** (`A`): 녹화된 패턴을 봇이 직접 쳐줌 (소리 + 입력 바 + 점프 표시). 재녹화가 맞게 됐는지 귀로 확인용.
- **구간 재녹화**: 하단 바에서 구간 드래그 → `T`. 구간 1.5초 전부터 기존 패턴 가이드 소리를 들려주고 구간 안만 교체. 패턴 끝 뒤를 선택하면 이어서 추가.
- **되돌리기**: 마지막 녹화/재녹화/불러오기 1단계 취소.
- 브라우저에 자동 저장 + JSON 파일 저장/불러오기.

## GD와 같이 쓰기 (전역 입력)
1. `build.cmd` 실행 → `gdpt-helper.exe` 생성 (윈도우 기본 C# 컴파일러 사용, 설치 불필요)
2. `gdpt-helper.exe` 실행 → 브라우저에 트레이너가 열림 (`http://localhost:8123`)
3. GD 창을 누르고 플레이. 트레이너 창이 포커스 아닐 때 helper 입력이 들어감 (상태줄 `전역 입력 ON`).

- 점프 입력: Space / ↑ / W 전부 (마우스 클릭은 무시). 여러 개 동시에 눌러도 버튼 하나로 처리 (싱글 모드).
- GD 안에서 쓰는 단축키: F6 녹화, F7 구간 재녹화, F8 연습(재시작), F9 정지, F10 매크로 재생, F11 GD로 매크로.
- **R 리스폰 동기화** (기본 켜짐, 설정 칸): GD에서 **R(재시작) 누른 순간 = 0초**.
  - 녹화/구간 재녹화/연습: 시작하면 `R 대기` → GD에서 R 누르면 시작. 죽어서 R 다시 누르면 그 판은 버리고 처음부터.
  - GD로 매크로: helper가 R을 직접 누르고 레벨 처음부터 모든 노트를 쳐줌 (구간 선택 시 구간 끝까지).
  - 끄면 예전처럼 첫 클릭 기준.
  - R 대기는 GD에서 F6/F7/F8로 시작할 때만. 사이트에서 버튼/키(R·T·P)로 시작하면 GD 없이 바로 진행 (카운트다운 또는 첫 클릭 동기화).
- **GD로 매크로** (`G` / GD 안에서 `F11`): helper가 GD에 Space를 대신 눌러줌. 패턴이 실제 게임에서 통과되는지 확인용.
  1. 구간 선택(또는 시작 위치) 후 `G`/`F11` → 상태줄 `GD 매크로 대기`
  2. GD에서 레벨 시작, **첫 노트만 직접** 누르면 나머지는 helper가 1x로 이어서 침 (첫 노트가 기준점)
  3. `F9`로 중단. 대기 중엔 아무 점프 키나 누르면 시작되니 GD 창에서만 누를 것.
- **첫 클릭 동기화** (기본 켜짐): 연습 시작 후 첫 클릭 순간을 첫 노트로 맞춤. GD에서 죽으면 F8 → 다시 시작.
- 주의: helper 켜져 있으면 다른 창에서 누른 Space / ↑ / W도 입력으로 들어감. GD를 관리자 권한으로 실행했다면 helper도 관리자 권한으로 실행.

## 조작
| 키 | 동작 |
|---|---|
| Space / ↑ / W | 점프 (홀드 가능) |
| R | 전체 녹화 (Esc로 종료) |
| T | 선택 구간 재녹화 |
| P | 연습 (구간 선택 시 그 구간, 아니면 시작 위치부터) |
| V | 리플레이 |
| Esc | 정지 |

하단 바: 드래그 = 구간 선택, 클릭 = 시작 위치 이동. 레인 위 휠 = 스크롤.

## 실행
`index.html` 더블클릭, 또는 GitHub Pages로 배포.
